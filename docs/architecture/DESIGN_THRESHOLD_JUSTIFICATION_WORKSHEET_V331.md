## 3. 可接受的补充证据路径

### 3.1 企业或导师确认的决策阈值

可提供一页结构化记录，说明多大幅度的信任或预期重复选择变化会触发企业改变以下至少一项决策：内容制作、媒介投放、响应时机、监测资源或危机预案。记录至少包含：

- 决策对象与责任角色；
- 指标及单位；
- 触发何种具体资源或策略变化；
- 阈值的形成依据；
- 日期、确认人和适用业务情境。

只有当记录能把0.15/0.05与具体决策联系起来时，才可以讨论“管理重要性”；一般性“看起来合理”不足以完成此项。

### 3.2 可比经验研究或企业历史数据

可接受材料包括绿色品牌危机前后同一信任量表的纵向数据、澄清内容A/B测试、品牌选择/复购面板或可核验的企业危机案例量化记录。必须核对：

- 构念与本研究estimand是否相同；
- 量表范围及AUC/时间窗口是否可换算；
- 百分点与相对百分比是否混用；
- 样本、品类、市场和危机类型是否可比；
- 引用是否能追溯到原文、出版社页面或原始企业记录。

文献只能支持其实际报告的效应和情境，不能仅因研究主题相近就为0.15或0.05背书。若需要新增文献，必须先核验作者、年份、题名和原文对应数值，禁止虚构或从二手摘要推断。

### 3.3 测量分辨率与可靠性依据

若未来获得Trust量表的可靠性或重复测量误差，可评估0.15是否小于可区分的测量变化。但本模型Trust是0—10工程状态，不是直接施测量表；现实量表的最小可检测变化不能未经映射直接移植为模型阈值。

## 6. Pilot前冻结规则

1. 若在Pilot前获得可核验管理或经验依据，可发布协议修订并说明阈值是否改变；任何改变必须使旧OC计划作废并重新冻结。
2. Pilot一旦开始，0.15/0.15/0.05不得根据Pilot均值、符号、方差或图形修改。
3. 若依据仍缺失，论文继续使用“预先设定的设计阈值”，不得用“管理上重要”包装。
4. 即使均值达到阈值，也必须与主分析不确定性和N=10诊断同时报告。
5. 即使均值未达到阈值，也不能自动得出等效或无效结论。
