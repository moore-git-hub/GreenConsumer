# 第一、二章编辑审计记录（v3.3.1）

## 1. 本轮目标

本轮对第一章绪论和第二章文献综述进行结构性精修，目标不是增加篇幅，而是建立以下论证链：

```text
绿色快消品信任危机的管理决策
→ 现有研究分别解释个体评价、网络暴露或购买意向
→ 不同证据对象无法自动组成跨层动态机制
→ 研究需要同时表示复合文本、历史状态、网络暴露与重复选择
→ 采用受约束语义评价＋规则更新的GABM
→ 内容、渠道、时机及总体澄清问题分别对应P1—P5
```

## 3. 尚未解决的审稿风险

### 3.1 结构性风险

1. 题目中的“绿色消费扩散”仍宽于实际的植物奶品牌信任修复与预期重复选择。完成正式blocks可以补足模型内推断，但不能消除外推范围差异。
2. “社会网络机制”目前主要由固定网络上的Hub/Random投放和工程拓扑稳健性支撑，尚未识别现实网络结构、同质性选择或算法推荐机制。
3. 理性证据型与情感共情型是复合刺激，P2不能回答证据、可信度、效价、唤醒或共情的独立效应。
4. 20个工程Persona没有经验权重，模型不能估计真实消费者异质性分布。
5. 心理更新、购买机会与重复选择参数未校准，正式blocks只能提高模型内重复推断，不能自动产生外部效度。

### 3.2 可通过后续工作缓解的风险

1. Pilot后按预设四相关场景和90%功效规则计算`N_required`；不得用正式结果反向修改门禁。
2. 正式结果报告全部block值、Holm family、联合LOBO和exact sign-flip敏感性，避免小样本结论依赖单一block。
3. 在第五章分别报告直接触达、信任、意向与重复选择，禁止以reach代替说服或购买。
4. 在第六章将管理启示写成模型条件下的情景推演接口，不写现实最优策略。

## 4. 引用处理

本轮未新增文献。所有作者—年份—题名继续来自已核验的用户文献包或已登记的官方包外来源。新增文字只重组既有主张、研究设计和证据边界，不将一般理论文献用于为N、Tick、网络、传播概率或行为参数背书。

## 5. 当前编辑判断

第一、二章已经形成比上一版更清晰的研究动机和方法选择逻辑，但尚不能支持强理论创新声明。当前最可信的增量是：把复合危机文本、可审计状态更新、固定网络暴露和重复选择连接为跨层计算机制，并严格区分模型内推断与现实效度。若正式blocks完成而现实校准仍缺失，论文仍应定位为机制建模与计算实验研究，而非现实策略效果研究。
