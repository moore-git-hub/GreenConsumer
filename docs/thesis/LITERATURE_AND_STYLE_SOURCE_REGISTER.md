## 3. 同专业硕士论文样本

用户提供5篇同专业硕士论文：

1. 《Z世代消费者绿色消费行为影响因素研究》；
2. 《“漂绿”感知对消费者绿色购买意愿的影响机制研究》；
3. 《基于目标框架理论的游客绿色消费意愿形成机制研究》；
4. 《漂绿广告伪善感知对消费者品牌信任的影响因素研究》；
5. 《环境事件对绿色消费行为的影响机制研究》。

这些论文只用于学习本学院/同专业常见的中文表达、标题层级、章节顺序、图表说明、结果讨论和管理启示写法。不得复制段落，不得因样本论文引用某文献就跳过对原文的核验。

### 3.1 提取出的共同写作规范

- 绪论通常按研究背景、目的与意义、文献综述/研究现状、研究内容与方法、技术路线、创新点展开；
- 理论章节先界定核心概念，再说明理论适用性，避免把理论名称堆叠成平行输入；
- 研究模型/机制章节需要明确变量关系、路径与边界；
- 研究设计与结果分析分章，先说明数据/实验和测量口径，再报告结果；
- 结果讨论按研究问题或路径逐项回应，管理启示必须从结果推出；
- 每章设置“本章小结”，图表采用连续编号和可独立理解的标题/注释；
- 中文表述以完整段落和递进论证为主，避免PPT式短语堆叠；
- 局限性单列，不能用“未来可进一步研究”掩盖当前识别不足。

### 3.2 本研究不能照搬的部分

样本论文主要采用问卷、结构方程、情景实验或扎根理论，其“样本量—信效度—显著性”结构不能直接套用于GABM。本文必须把replication block与Agent区分，并以ODD/ODD+D、代码traceability、seed ledger、敏感性和正式重复推断替代问卷信效度叙事。

## 7. 待补充资料触发条件

当前不需要立即补充文献包。只有出现以下情况时再向用户索取：

1. 某项核心中文命题无法从现有PDF辨认完整书目信息；
2. 学校要求的参考文献格式模板或官方论文Word模板尚未提供；
3. 论文需要现实植物奶市场数据、消费者调查或平台网络数据作为外部验证；
4. 需要引用导师指定但不在七个文献包中的特定研究；
5. 当前53个唯一PDF不足以覆盖ODD+D、pattern-oriented modeling、face/micro/macro validity中的某一具体方法主张。
